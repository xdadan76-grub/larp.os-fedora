
# larp.os-fedora — Desktop Identity

## Visual Philosophy

A modern, dark, elegant and futuristic desktop.

## Official Branding

- Distribution: larp.os-fedora
- Official logo: Custom skull logo provided by the creator.
- Logo must preserve its original shape.
- Consistent branding across the system.

## KDE Plasma

- Desktop: KDE Plasma
- Display server: Wayland
- Login manager: SDDM
- Default theme: Custom larp theme

## Appearance

- Dark interface.
- Minimalist desktop.
- Clean application menus.
- Modern window decorations.
- Subtle animations.
- Custom system icons.
- Exclusive wallpapers.

## Colors

- Background: Deep black.
- Secondary background: Dark graphite.
- Primary accent: Electric cyan.
- Secondary accent: Violet.
- Text: White and light gray.

## Customization Targets

- Plasma panel.
- Application launcher.
- System settings.
- Dolphin.
- Konsole.
- SDDM login screen.
- Boot splash screen.
- System notifications.

All visual elements must maintain a consistent
