
# larp.os-fedora

**A custom Linux distribution based on Fedora KDE Spin.**

larp.os-fedora is an independent Linux distribution focused on performance, customization, security, and a modern desktop experience.

# Main Features

- Fedora Linux base
- KDE Plasma desktop environment
- Custom larp.OS branding
- Personalized login screen
- Custom boot animation
- Exclusive wallpapers and icons
- DNF package management
- Flatpak and Flathub support
- Live ISO environment
- Graphical system installer
- UEFI boot support

# Visual Identity

larp.os-fedora features its own visual identity, including a custom skull logo, dark themes, wallpapers, icons, and desktop customization.

# Technologies

- Fedora Linux
- KDE Plasma
- RPM
- DNF
- Kickstart
- Lorax
- Anaconda
- Flatpak

# Project Structure

- `branding/` — Logos and wallpapers.
- `config/` — System configuration.
- `desktop/` — KDE customization.
- `build/` — ISO build scripts.
- `installer/` — Installation configuration.
- `scripts/` — Automation tools.
- `tests/` — System validation.
- `docs/` — Project documentation.

# Architecture

- x86_64

Under development.

# Goal

Build a complete, independent Fedora-based Linux distribution with its own identity, customized desktop, installation experience, and reliable ISO.
